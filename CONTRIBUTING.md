# Участие в разработке

Спасибо за интерес к проекту! Будем рады issue и pull request'ам.

## Сообщить о проблеме

Откройте [issue](https://github.com/avito-tech/avito-ads-sdk-go/issues) и опишите:

- что вы делали и что ожидали получить;
- что произошло на самом деле (по возможности — минимальный пример кода);
- версию SDK и Go (`go version`).

Не включайте в issue реальные `client_id`, `client_secret`, токены и другие секреты.

## Pull request

1. Сделайте форк и создайте ветку от `main`.
2. Внесите изменения и добавьте тесты на новое поведение.
3. Убедитесь, что всё проходит локально:

   ```bash
   go build ./...
   go vet ./...
   gofmt -l .            # вывод должен быть пустым
   go test ./... -race
   ```

4. Оформите коммиты осмысленно и откройте pull request с описанием изменений.

CI прогоняет эти же проверки на Go 1.21, 1.22 и 1.23 — PR должен быть зелёным.

## Стиль кода

- Код форматируется `gofmt`; внешние зависимости не добавляются — SDK построен только на стандартной библиотеке.
- Публичные типы и функции снабжайте doc-комментариями.
- Все методы, делающие сетевые вызовы, принимают `context.Context` первым аргументом.
